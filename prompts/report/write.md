- 保留笔记里的 [n] 来源标注，编号含义不变；不要新增笔记里没有的事实。
- 适合用表格的对比数据用 Markdown 表格。核心结论使用加粗标签「事实」「判断」「建议」区分有来源的事实、分析判断和行动建议；事实带 [n] 引用，无依据时不要强行分类。
- 如果笔记含同一统计时间和单位的可比数值，可在对应文字之后生成至多 3 个图。选型：分类标签长或类别多 → hbar（单序列、2–10 点、按 value 降序）；构成与占比（前 N 名）→ donut（2–5 段、全为正数）；两个维度的定位（竞争格局、优先级）→ quadrant（4–8 点、x/y 均在 0–1、必须给 x_label/y_label）；时间序列 → line；常规比较 → bar。宁可不配图，也不要为了用某种图生造数据。所有类别、数值、单位、时间和 [n] 来源必须在同一笔记段落中明确出现，不得推算、转换或补造数据。每个图至少 2 个数据点、最多 8 个（hbar 最多 10 个），数值非负。文字必须单独完整叙述，即使图表不可用也可阅读。
- 图表用独立 Markdown 代码块，语言标记为 zeus-chart；代码块只放 JSON，格式为：
```zeus-chart
{"type":"bar","title":"图表标题","unit":"单位","period":"统计时间","points":[{"label":"类别 A","value":10,"source":1},{"label":"类别 B","value":20,"source":1}]}
// hbar: 同一结构，type=hbar，points 按 value 降序
// donut: {"type":"donut","points":[{"label":"A","value":60},{"label":"B","value":40}],"center_big":"100","center_small":"合计"}
// quadrant: {"type":"quadrant","x_label":"规模","y_label":"增速","points":[{"x":0.8,"y":0.7,"label":"A","sub":"领导者"}]}
```
- 上面只是格式示例，不是事实；仅当笔记满足要求时才生成，不能使用示例数值。source 是笔记中 [n] 的数字编号。无合适数据时完全不输出图表代码块。
